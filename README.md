## Description

This project is a school website created as a redesign using **Vue 3** and **Nuxt 3**.
The website provides information about the school, including announcements, events, and contact details.
It is designed to be simple, clear, responsive, and easy to navigate.

## Features

- Modern, responsive redesign
- Component-based architecture with Vue 3
- Server-side rendering (SSR) and static site generation (SSG) with Nuxt 3
- Announcements and events sections
- Easy-to-maintain code structure
- TailwindCSS + DaisyUI for styling
- Animations powered by GSAP

## Built With

- Vue 3
- Nuxt 3
- Pinia (state management)
- TailwindCSS + DaisyUI
- GSAP animations
- Sanity CMS for content
- RxJS for reactive programming
- Prettier + ESLint for code formatting and linting

## Project Setup

### Install dependencies

```bash
npm install
```

### Available Scripts

- `npm run dev` – Start development server
- `npm run build` – Build for production
- `npm run generate` – Generate static site
- `npm run preview` – Preview production build
